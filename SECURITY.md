# Security policy: Knitwise Assess

Knitwise by Blore.AI publishes this Action as `knitwise-dev/assess`.

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- Use GitHub's **Report a vulnerability** button on this repository's **Security** tab (private vulnerability reporting).

Include the Action version, what you found, and how to reproduce it. We'll acknowledge within 3 working days and tell you what we'll do and when.

## Supported versions

| Version | Supported |
|---|---|
| Latest release of the current major version (`v0`) | Yes |
| Older releases | No: please update to the latest |

Pin to the major tag (for example `@v0`) to receive fixes, or to a full commit SHA if your policy requires it.

## What the Action can and cannot do

See the [security FAQ](docs/pilot/security-faq.md): what it reads, what it never reads, its network calls (read-only, `api.github.com` only), what it writes, and how to audit it.
